## Important distinctions
1. Training crawlers (e.g. GPTBot, Google-Extended, ClaudeBot) are not equivalent to search and retrieval crawlers.
2. `robots.txt` permission is not proof of inclusion, recommendations or traffic.
3. Yahoo/DuckDuckGo do not have the same first-party ranking report as GSC; use controlled SERP samples and referral data without claiming all results are Bing.
4. Google Search Console's 2026 Generative AI report is a dedicated UI report; the standard Search Analytics API cannot be assumed to reproduce all AI-only fields.
5. Bing AI Performance can provide citation visibility in supported Bing experiences; not proof that every Copilot conversation cites the page.
6. All AI checks must record country, device or access mode, date/time, engine version if known, exact prompt, completion status, competitors, owned citations and evidence URL/screenshot. Missing responses are excluded from rates.
7. Do not post fabricated reviews, forum spam, self-citations or unsupported superlative claims; third-party recognition must be legitimate.
